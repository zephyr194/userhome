# Spec: ui-visual-system-v3

状态：2026-10-10 已获用户审批。依赖：无。替代 `visual-system-v2` 中与本修订冲突的字型、尺寸和外观实现要求；不改变业务语义。

## 目标

建立覆盖全部主路由的单一视觉语言，消除页面各自定义字号、控件尺寸和间距所造成的拼接感。统一指的是相同语义使用相同令牌与组件，而不是强制单一深色外观。

## 能力与验收

- 外观继续支持 `SYSTEM`、`LIGHT`、`DARK`。System 跟随 macOS；Light 与 Dark 均完整可用。切换外观不改变布局、不丢失路由、选择、筛选或草稿。不得把任意已持久化值强制渲染成 Dark，也不得把默认值从 System 改为 Dark。
- 全局仅使用 `src/styles/global.css` 的 `--app-*` 语义令牌发放画布、表面、边界、正文、次要文字、选中、焦点、成功、警告和危险颜色。页面不得维护独立色板、装饰渐变或依赖透明叠色制造不可核验的正文颜色。
- 字体统一为 macOS 系统无衬线栈；代码、命令和安全相对路径使用统一等宽栈。基础正文 13px、辅助信息 12px、紧凑元数据 11px、分组标题 14px、页面标题 20px；仅标题使用 600–700 字重，正文不靠大面积粗体制造层级。正文行高不低于 1.4，辅助说明不低于 1.35。
- 标准按钮、输入框和选择框为 32–36px；单行资源行为 36–44px，双行资源行在默认字号下不超过 64px。相同控件在 Dashboard、Applications、Homebrew、Services 和 Settings 上拥有相同高度、圆角、边界、内边距、悬浮、焦点、禁用和忙碌状态。
- 间距只使用共享语义刻度。页面标题、分组标题、字段标签、帮助文案、列表行和详情元数据各自形成固定层级，不允许通过页面局部 `font-size` 或任意 padding 修补对齐。
- 普通文本和有意义图标实际渲染对比度至少 4.5:1；大文字、焦点、边界、选中态至少 3:1。状态必须同时提供文字或图形线索。
- 200% 文本缩放允许控件和行增高；不得用固定高度、`line-clamp`、裁切或隐藏溢出来保持视觉整齐。

## 实现边界

优先复用 `src/components/ui/` 和设置原语；先收敛令牌和共享组件，再迁移页面。可删除已无调用的旧类，但只有在五个主路由均完成迁移后才能删除兼容样式。

### 始终

- 保留可见焦点、reduced-motion 和原生控件语义。
- 为相同语义使用同一组件或同一组令牌。
- 用真实内容长度、错误文案和中英文混排验证尺寸。

### 先问

- 新增 UI 依赖、改变外观偏好 schema、增加字体资源或新增测试用例。

### 绝不

- 强制固定深色、隐藏外观设置、使用页面私有字号体系，或以缩小文字解决溢出。

## 验证

运行 `pnpm lint && pnpm typecheck && pnpm test && pnpm build`。人工在 System/Light/Dark、100%/200% 文本缩放下逐路由核对字型、控件、焦点和实际对比度；未人工检查的组合标记为“待验证”。
