# Spec: visual-system-v2

状态：2026-09-23 已获用户审批。依赖：无；向 `desktop-shell-v2` 与全部页面提供视觉令牌和共用控件约定。

## 目标与用户

面向在 macOS 上管理本机环境的开发者，将现有偏绿且层级繁杂的界面变为克制、可信、易扫描的原生实用工具。颜色只辅助识别，布局和文字承担主要信息层级。

## 能力与验收

- Light：以偏冷灰白画布、白色内容面和石墨字色为主；Dark：深石墨画布与较亮的内容面。主操作及当前选中态采用一套蓝色语义强调；危险、警告、成功各保留专属语义，不得全部染蓝。System 跟随 macOS，切换外观不改变布局或丢失选择。
- 候选基色（实现前允许在符合对比度前提下微调）：Light 画布 `#f5f6f8`、表面 `#ffffff`、侧栏 `#edf1f5`、正文 `#17212e`、强调 `#1663b7`；Dark 画布 `#171c24`、表面 `#202732`、侧栏 `#1b222d`、正文 `#edf2f9`、强调 `#82baff`。颜色统一由 `--app-*` 语义令牌发放，不在页面写独立色板。
- 正文 13–14px、次要信息 11–12px、页面标题 18–22px；通过字重、间距和分隔线区分层级。每组页面的主按钮、次按钮、危险按钮、状态标签、输入、选择、空态和加载态具有一致的尺寸、交互及焦点样式；禁止大面积阴影、装饰性渐变与密集的状态胶囊。
- 普通文本和有意义图标的对比度 ≥ 4.5:1；大号文字、组件边界、选中态及焦点指示 ≥ 3:1；禁用状态无需满足常规文本阈值但必须清楚且不可误认成可点击。所有状态需文字或图形辅助，不能仅凭颜色。
- 标准控件高度 32–36 逻辑像素，资源单行 32–44、双行不超过 64；重复间距使用现有语义间距令牌。在 100% 和 200% 文本缩放下允许内容行增高，不以固定高度裁掉信息。

## 技术、目录及风格

沿用 Tauri 2 / React 19 / TypeScript / Tailwind CSS 4 / Headless UI。令牌放在 `src/styles/global.css`，共用语义组件放在 `src/components/ui/`，外观偏好沿用 `src/app/appearance.ts`。示例：

```css
.resource-row[aria-selected="true"] {
  color: var(--app-selection-foreground);
  background: var(--app-selection);
  border-color: var(--app-selection-border);
}
```

`PascalCase` 命名组件、`camelCase` 命名行为；状态只使用语义令牌，不能在每个页面另造配色。

## 验证

命令：`pnpm lint && pnpm typecheck && pnpm build`，然后在集成阶段运行 `pnpm check`。人工逐一核对 Light/Dark/System、正常/悬浮/焦点/选中/禁用/加载/警告/错误/危险，以及文本和焦点的量化对比度。沿用现有测试，不新增测试用例。

## 边界

- 始终：维护 `--app-*` 语义映射、无障碍名称、可见焦点及 reduced-motion 行为。
- 先问：新增 UI 依赖、改变危险/警告的含义、扩大窗口、增加测试用例。
- 绝不：只凭蓝色表达结果、在页面任意硬编码对比度未验证的颜色、隐藏焦点。
